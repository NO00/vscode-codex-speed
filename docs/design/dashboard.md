# 仪表盘设计

## 交互

状态栏悬浮保留速度、来源、会话数、模型及主机摘要；点击状态栏通过原有 `codexSpeed.showDetails` 命令打开单例 Webview。新增 `codexSpeed.openDashboard` 命令作为独立入口。0.1.6 改为开发者监控台视觉：移除圆形速度表，使用数字读数与并排趋势图、连续用量数据带和对齐的会话表格。0.1.7 使用蓝色实测线与浅蓝绿色估算线，亮色主题将估算色加深以保证辨识。会话行增加短 ID，便于区分同名目录。语言、刷新与设置位于顶栏，连接元数据默认折叠。

0.1.8 对齐 Agent Speed 的 Codex 核心测速体验：主读数按最近三秒合计实测和在途估算，曲线按最近三百个一秒桶重建，实测与估算分别保存。完成记录到达后，按实际输出和有效区间重建过去对应的秒，替换原在途估算。界面保留独立布局与蓝／蓝绿色配色；蓝线表示实测部分，虚线表示含估算合计。主读数与某个一秒值不必相同，当前未结束的一秒仅含已覆盖部分。

工具阶段仍可显示刚完成请求在三秒窗口里的贡献，窗口排空后归零。最近调用速度不再保留十五秒；次要文字独立展示最近调用及时间。估算值、占比、实测组成在读数下方展示，不再以一个二元标签掩盖混合数据。

## 响应式展示

宽屏实时区为读数与趋势两列，用量为四列，会话模型、输出和速度按列对齐。740 像素及以下改为上下趋势、两列用量和紧凑会话行；极窄窗口单独压缩字体与次要信息。曲线通过 ResizeObserver 根据实际宽度绘制，固定字号坐标保持可读，面积底色不跨越未观测断档。五分钟峰值属于实时区，与历史用量范围独立。

所有动态路径、ID 和模型名仍用 textContent 写入，行内短速度条只表示已有速率的相对长度，不编造会话历史或动画数据。详情使用原生 details/summary 支持键盘展开，按钮和选择器保留可访问名称；尊重减少动态效果偏好。

## 模块与数据

`src/engine.ts` 的 `calculateFrame` 共用作用域、镜像合并、响应去重和参考选择，产出全局快照、会话快照及可选历史桶。状态栏省略历史计算，面板可见时重建三百桶。完成响应按区间均匀分配，未完成区间依据本会话近十分钟最后三次完成响应估算；缺少参考时回退同模型、同来源近半小时最后十次。有效区间为非倒序且不超过十五分钟，最短按五百毫秒计速。未知耗时仍可计用量，但不产生测速参考。

历史不保存轮询时的旧估算；迟到完成记录、启动和关闭重开都从已有解析记录重建。差分数组处理完整秒，首尾秒按毫秒交集分配；同一份记录只遍历建立一次索引，避免按会话重复扫描全部响应。悬停与键盘光标查询当前重建后的数据，因此校正后不会显示缓存的旧估算。

用量按响应身份全局去重，镜像会话按会话 ID 合并显示。0.1.5 起，历史用量由 `src/history/` 单独索引，范围为近半小时、客户端今天、近七天、近三十天。平均速度为已知耗时响应的输出总量除以耗时总量。实时样本仍有尾读和每会话 1000 条上限，历史索引从头读取，不受这两个实时保留上限限制；可用日志、索引进度和资源上限仍会影响历史完整性。

`panel.ts` 负责 Webview 生命周期和有限消息，`html.ts` 负责固定结构，`messages.ts` 汇总本地化文案。界面 CSS/JS 位于 `assets/dashboard/`，与计数及日志解析分目录，避免扩展入口或单层目录继续膨胀。

已有轮询默认每五百毫秒读取新增日志，并以独立字节预算推进历史用量回填，用户已设置的间隔仍有效。只有 Webview 可见时才构造曲线和汇总，通过消息更新 DOM，不重新加载整份页面；关闭后释放监听和 Webview，日志监控继续运行。五分钟峰值取重建桶的三秒平均与当前读数的最大值，可能含估算并会被完成记录校正。

## 隐私与资源

Webview 无网络访问权限，脚本和样式仅从打包资源加载，脚本使用随机 nonce。模型、目录、名称等动态值通过 JSON 消息传递，以 `textContent` 写入，不能成为 HTML 或命令。页面消息只允许刷新、打开设置、切换已列出的语言，不能传入任意命令或日志路径。

历史缓存只保存计数、时间、来源目录、解析状态与完整行断点，不保存原始行和对话正文；按 Codex Home 摘要隔离，多窗口共享一个写入者。当前最多 12000 个缓存文件项、250000 条响应、64 MiB 缓存文件，目录发现最多 20000 项，达到上限会提示结果可能不完整。缓存损坏会回填仍可访问的日志，写入不可用时改为内存统计。

今天的零点使用仪表盘客户端报告的 IANA 时区，通过日历边界查找处理夏令时；缓存存储原始时间戳，因此切换范围和客户端时区不必重新读取日志。源文件截断或替换会使对应断点和记录失效；已删除源文件的已缓存计数保留至三十天窗口过期。

浏览器视觉预览通过 `scripts/dashboard/preview.sh` 启动，仅监听本机回环地址，使用同一份 HTML/CSS/JS 和完全虚拟的日志数据。预览在显著位置标注虚拟数据；该服务、样例及截图均排除出 VSIX，不参与正式运行。

## 语言与验证

仪表盘继承 `codexSpeed.language`，顶栏选择器更新同一配置，支持跟随 VS Code、英文、简体及繁体中文。隐藏或停用监控时也允许语言更新。命令标题及设置说明继续由 VS Code 原生清单本地化管理。

运行 `bash scripts/test.sh` 检查模型、翻译、去重与曲线边界；`bash scripts/host-test.sh` 验证 Webview 实际脚本回传渲染确认、关闭重开和语言更新。`bash scripts/package.sh` 检查打包资源。翻译新增时，可向 `scripts/dashboard/update-locales.sh` 传入按语言分组的补充 JSON；该工具从实际调用提取键，缺失翻译则拒绝覆盖。

## 参考口径与范围

参考 [Agent Speed 测速规范 6.2／6.3／6.5](https://github.com/zoefix/agent-speed/blob/a94a67fcc78e5d8eea5f82d8d5e737bccf994e2c/spec/METRICS.md#6-engine)。`tests/fixtures/agent-speed-engine.json` 保留原版全部来源为 Codex、响应为最终记录的十一组案例及完整 MIT 许可，测试仅比对本扩展支持的输出速度、估算占比与存在的历史期望。分桶另与独立逐区间公式交叉核对。

这不是整个 Agent Speed 的移植：不提供它的其他 agent 来源、压缩与归档日志、费用、网络流量、总输入吞吐或每日峰值存储。日志发现、有界读取、作用域和当前保留上限也会影响两个工具读取到的数据集，不能保证两者在不同主机、不同范围下显示完全相同的数字。
