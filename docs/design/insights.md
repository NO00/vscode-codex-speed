# 运行概况：额度、首段等待与模型速度

2026-11-12，版本 0.1.12。参考 [Agent Speed 1.8.0 的额度规范](https://github.com/zoefix/agent-speed/blob/ce952fe844b2ab5d3aa45c542b8e1fe67e0ca689/spec/QUOTAS.md#3-codex)和[测速规范](https://github.com/zoefix/agent-speed/blob/ce952fe844b2ab5d3aa45c542b8e1fe67e0ca689/spec/METRICS.md)。三秒测速主公式、价格快照和计费算法保持原有口径；没有复制上游网络服务、认证读取、额度金额上限推算或角色动画。

## 账户额度

`CodexParser` 在继承历史过滤之后独立处理 `event_msg` 的 `token_count` 额度。即使用量缺失、重复或已经转为现代用量，也接收有效额度；无有效窗口或更旧时间不覆盖快照。

- 只接收 `limit_id` 为 `codex`、空或缺失的快照。周期必须提供有限数值的已用百分比及正分钟数。五小时兼容 290–310 分钟，周周期兼容 10000–10160 分钟，其余按实际长度显示。
- 同类周期优先 `primary`，不同长度的其他周期分别显示，最多两项。重置优先 Unix 秒 `resets_at`，兼容按记录时刻计算的 `resets_in_seconds`。未知时间单独标识，明确的零值保留。
- 所有已跟踪文件只选服务器时间最新且不在未来的一份快照，不把百分比相加。账户信息不受工作区或历史用量周期过滤；这里只表示该目录最后观察到的账户，不能据此识别或合并多个账户。
- 百分比绘制限制到 0–100，保存厂商原始值。超过一小时显示旧快照及绝对记录时间。过重置时刻后保留旧读数并明确等待新日志，不假定当前周期用量为零。这一点有意比参考程序按时钟归零更保守。
- 套餐名只显示日志明确给出的短字符串。没有额度不猜测套餐、剩余百分比或金额上限。不读取认证、浏览器缓存或状态行，不调用实验额度接口。

额度来自实时跟踪文件的可用尾部。长期未更新或超出扫描、尾读上限的日志可能没有可用额度；没有独立持久化账户快照，也不为额度另扫历史。

## 首段内容等待

响应样本和当前请求新增可选的 `firstContent` 时间。首次 reasoning、assistant 消息或工具调用事件设定该字段；后续片段不覆盖。输入开启下一请求、响应结束、取消和任务完成时清理。邮箱起点沿用地址匹配规则。检查点保存当前首段时间；旧的流式检查点缺少此字段时保持未知，不能把恢复后的片段冒充首段。

该时间是日志落盘的观测值，不是网络首 token 时间。只在请求起点和首段均有效、顺序正确、请求区间不超过十五分钟时生成完成等待值。

| 状态 | 读数 |
| --- | --- |
| 当前仍有请求等待首段 | 最久请求已经等待的毫秒数，界面加 `≥`，附等待请求数量 |
| 活跃请求均已观察首段 | 已观察首段等待的算术均值，附请求数 |
| 没有可用活跃生成请求 | 最近半小时中最新可确认完成调用的等待及完成时间 |
| 起点／首段缺失 | 暂无数据，不输出伪造的零 |

同一会话镜像按最近状态合并，完成样本按响应键去重。工作区过滤、五分钟失联和未来时间排除与会话视图一致。元数据仅保存时间，无正文。历史记录允许保存可选首段字段，旧缓存向后兼容；此功能不触发全量费用历史迁移。

## 按模型速度

`calculateFrame` 把用于主读数的每份贡献同时按模型累加：完成记录采用自己的 `sample.model`，生成估算采用会话当前上下文模型。分组不另建估算参考，也不从会话最终显示的模型反推完成记录归属。

各模型总速度之和与主读数一致；实测、估算及估算占比分别保留。分组还包含当前生成、工具数和关联独立会话数。速度归零但仍活跃的模型保留，完全空闲且没有窗口内贡献的模型消失。未知模型保留可计数速度，由界面翻译名称；不限制模型白名单、不推断新价格。

## 界面及验证

新增运行概况放在趋势下方、用量之前：宽屏并排显示等待和账户额度，下方展示模型速度；窄屏纵向排列。所有日志字段通过 `textContent` 插入，保留 Webview 的 CSP。原有自动、英文、简体和繁体中文切换即时更新全部新文案、日期、倒计时和数字格式。

核心回放覆盖额度缺失、空周期、重复用量、继承过滤、旧快照、未来时间、检查点恢复、取消、首段缺失、并发等待和模型切换后的速度守恒；真实 VS Code 宿主再验证前端渲染、语言切换和跨模型并发。预览全部使用虚拟数据。
