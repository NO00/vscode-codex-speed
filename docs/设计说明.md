# 设计说明

## 数据路径

```text
Remote SSH 服务器上的 ~/.codex/sessions/**/*.jsonl
    ↓ 只读、按字节偏移增量读取
TranscriptTailer → CodexParser → calculate
    ↓ 状态快照，不含对话内容
VS Code workspace 扩展宿主 → 本机状态栏
```

`extensionKind: ["workspace"]` 使扩展随远程工作区运行；直接使用扩展宿主的文件系统和用户目录，无需建立第二条 SSH 连接。协议处理、测速计算、文件读取和 VS Code UI 装配分离，核心逻辑可用显式时钟与虚拟文件回放。

## 模块边界

| 模块 | 责任 |
| --- | --- |
| `types.ts` | 定义响应、会话、监控选项和速度快照 |
| `parser.ts` | 新旧日志格式适配、响应计数、运行阶段和请求区间 |
| `tailer.ts` | 有界读取、半行恢复、截断及轮换重置 |
| `engine.ts` | 过滤、全局响应去重、三秒窗口、并行汇总及估算 |
| `monitor.ts` | 有界目录发现、轮询协调、故障恢复 |
| `logger.ts` | 输出通道与有界文件日志 |
| `extension.ts` | 配置、命令、状态栏和生命周期 |

## 速度口径

一次可测响应的平均速率为 `output_tokens × 1000 / (end_ms - start_ms)`。`start_ms` 是用户输入、任务开始或工具结果等引出的请求起点；`end_ms` 是日志用量记录时间。缺少请求起点或耗时非正数时不生成实测速率。`output_tokens` 自带 reasoning，不额外叠加。

三秒窗口的已完成部分为每条响应速率乘以它与窗口重叠时间的比例，再累加并行响应。生成中使用同会话近十分钟最后三条可测响应的总输出除以总有效耗时；缺少时回退同模型、同来源近半小时最后十条。参考只来自当前所选作用域。估算从请求开始和该会话最后完成时刻的较大值起算，避免与完成响应重复；数字前显示 `~` 并保留估算占比。首次会话且所有回退都没有参考时显示等待。

测速区间非倒序且不超过十五分钟，少于五百毫秒时把区间起点向前扩展至五百毫秒。所有速度平均使用同一有效耗时。历史按最近三百个一秒桶重建，分别累计实测和在途估算；完成记录到达后按实际计数覆盖原请求的估算。实线是按调用区间均匀分配后的结果，仍不是逐 token 观测。

实测数字本身也是根据日志事件时间推断的调用平均值，并非每秒收到的 token 分片计数。迟到的用量记录用于更新最近调用和计数，不把旧响应硬塞进当前窗口。服务器日志时间与计算时钟均来自同一个远程扩展宿主。

状态栏、主读数和会话速率共用三秒窗口；曲线显示一秒值，未完成的当前秒只累计已有覆盖部分。工具阶段保留三秒窗口内刚完成响应的贡献，窗口排空后归零；上次调用仅作为独立次要信息。实时保留和有界读取仍可能限制可见数据，历史用量使用独立持久化索引并提示完整性。

## 格式兼容和容错

现代格式只取 `token_usage_record.payload.usage`，按 `response_id` 去重；不读 `turn_token_usage` 和 `thread_token_usage` 作为新增量。出现现代记录后，忽略兼容 `token_count` 的重复用量。

旧版从 `total_token_usage` 差分；首次优先 `last_token_usage`，重复累计值不增加响应，累计回退时使用 `last_token_usage`。fork 的复制历史早于新会话创建时间时跳过，后续复制的 `session_meta` 不能覆盖首个身份。

文件按原始字节偏移读取，半个 UTF-8 字符不会提前解码。坏 JSON 和过大行被隔离，不影响后续事件。inode、设备号或创建时间改变，以及文件尺寸小于已读偏移时重建状态机。此版不针对原 inode 上等长覆盖进行内容哈希检测；标准 Codex JSONL 为追加写入，文件替换或截断可识别。

## 验证范围

单元及文件回放覆盖双格式去重、旧版重置、并行汇总、估算替换、工作区边界、未来事件、工具耗时排除、缺失时间、半行与中文跨字节、坏行、大行、大文件尾读、文件轮换、删除、目录缺失恢复及符号链接隔离。

真实本机 VS Code 扩展宿主测试覆盖扩展加载、workspace 运行位置声明、状态栏文字、估算开关、配置变更重启、追加计数及错误恢复。它验证运行装配，但不能替代实际 SSH 服务器上的连接和权限验收。
